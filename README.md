# ПЗ банкомата — прототип (ЛР3, варіант 13)

Тестовий прототип програмного забезпечення банкомата для лабораторної роботи № 3
з дисципліни «Конструювання програмного забезпечення»
(ВоФК НУХТ, група ППЗ-41, студент Чернік Михайло).

Проєкт продовжує лабораторні роботи № 1–2: реалізує модулі M1–M7,
визначені на етапі планування, мовою Python 3 з конфігурацією JSON
та журналом подій у SQLite (криптографічний ланцюжок SHA-256).

## Структура

```
atm/
├── config.json       — конфігураційна мова: ліміти, операції, касети
├── main.py           — демонстраційний сценарій роботи банкомата
├── core/             — M1: контролер, сесія, автентифікація
├── ui/               — M6: драйвери-заглушки пристроїв
├── gateway/          — M7: обмін із процесингом, симулятор банку
├── transactions/     — M2: клієнтські транзакції, добовий ліміт
├── journal/          — M3: захищений журнал (SQLite + SHA-256)
├── maintenance/      — M4: касети, диспенсер, режим SERVICE
├── security/         — M5: безпека, перевірка й відкат оновлень
└── tests/            — 25 модульних тестів (unittest)
```

## Запуск

```bash
python3 main.py
```

## Тестування

```bash
python3 -m unittest discover -s tests -v
```

25 тестів покривають клієнтські операції (FR-01–FR-13), обслуговування
касет (FR-15, FR-16), захист від втручання і контроль оновлень (FR-17,
FR-18), а також нефункціональні вимоги: ідемпотентність транзакцій
(NFR-02), відсутність PIN у журналі (NFR-01) і цілісність ланцюжка
журналу (NFR-06).

## Примітки

Прототип використовує драйвери-заглушки обладнання; у реальному
впровадженні їх реалізують на C/C++, а PIN обробляє апаратний
захищений модуль. Симулятор процесингу (`gateway/bank.py`) імітує
тестове середовище банку (симулятор з ЛР2, п. 1.4).
